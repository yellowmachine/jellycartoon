- **[JellyCartoon, la casa](/tecnica/casa/):** series, películas, música, radio y juegos en un
  ordenador de casa, para la tele, el móvil, la tablet y el coche.
- **[Seilide, la nube](/tecnica/seilide/):** lo que funciona aunque la casa esté apagada: agenda,
  nevera, gastos, la voz y el modo carretera.
- **[Satélite de voz](/tecnica/satelite/):** una Raspberry con micrófono y altavoz en una
  habitación, que habla con Seilide.

Esta es la parte técnica: instalar, configurar y cómo está hecho. La guía para la familia, con lo
que hace cada cosa y cómo se usa, está en preparación.
